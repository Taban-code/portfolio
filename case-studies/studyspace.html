A calmer starting point for learning.

StudySpace is a portfolio concept inspired by the value of making technical subjects easier to navigate. It explores how a small education website could organise revision resources and guide learners toward the topic they need.

This is a self-initiated concept created for portfolio demonstration. It is not presented as a commissioned client project or a launched education service.

The idea

Learning websites can become difficult to use when resources are scattered or presented without a clear structure. This concept explores a simple subject-first experience with concise topic cards and an obvious route into each learning area.

Subject claritySeparate Physics and Mathematics from the first interaction.
Easy scanningUse short descriptions and a clear visual hierarchy.
Mobile accessKeep the layout comfortable on smaller screens.
Room to growAllow future lessons, revision notes and practice activities.

Experience direction

The proposed experience starts with a clear introduction, then presents the two subject areas as distinct paths. Topic pages would use readable typography, structured explanations and clear navigation back to the subject overview.

The visual language pairs the portfolio's dark foundation with a restrained orange accent, while using spacing and strong headings to keep the interface approachable.

Proposed scope

This concept defines a possible interface and content structure. It does not claim that a live learning platform, lesson library, user accounts or assessment engine has been deployed.

Next steps

A future build could add a small set of original sample lessons, accessible practice questions and a searchable topic index. Any published educational content would be reviewed for accuracy before release.
